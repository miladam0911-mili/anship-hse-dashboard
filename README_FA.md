# داشبورد HSE کانشیپ — Vercel + Google Sheets

## امکانات
- رابط فارسی واکنش‌گرا برای موبایل، تبلت و دسکتاپ، بر پایه فایل HTML اولیه.
- ثبت حادثه، بازرسی، PPE، تجهیزات و وضعیت تناسب شغلی.
- ذخیره‌سازی مرکزی در Google Sheets و ساخت خودکار تب‌ها.
- رمز مدیریت برای ثبت، ویرایش، حذف و بستن حادثه.
- دانلود CSV هر بخش.

## راه‌اندازی
### ۱. Google Sheets و حساب سرویس
1. یک Google Spreadsheet بسازید.
2. در Google Cloud Console، Google Sheets API را فعال کنید.
3. یک Service Account بسازید و کلید JSON آن را دریافت کنید.
4. فایل Spreadsheet را با ایمیل `client_email` داخل JSON با دسترسی Editor به اشتراک بگذارید.
5. شناسه Spreadsheet از URL، بین `/d/` و `/edit` است.

### ۲. انتشار در Vercel
1. محتویات این پوشه را در یک مخزن GitHub قرار دهید.
2. در Vercel گزینه Add New → Project را بزنید و مخزن را Import کنید.
3. Framework Preset را روی Other قرار دهید و Deploy کنید.

### ۳. Environment Variables
در Vercel → Project → Settings → Environment Variables، این چهار مقدار را اضافه کنید:
- `ADMIN_PASSWORD`: رمز قوی مدیریت.
- `SESSION_SECRET`: رشته تصادفی محرمانه، حداقل ۳۲ کاراکتر.
- `GOOGLE_SHEET_ID`: شناسه Spreadsheet.
- `GOOGLE_SERVICE_ACCOUNT_JSON`: تمام محتوای فایل JSON حساب سرویس، به صورت JSON معتبر.

برای Production تنظیم کنید و سپس Redeploy بزنید. رمزها را در HTML یا GitHub قرار ندهید.

### ۴. تست نهایی
1. سایت Vercel را باز کنید.
2. تب‌های «حوادث»، «بازرسی‌ها»، «حفاظت فردی»، «تجهیزات» و «معاینات پزشکی» باید خودکار ایجاد شوند.
3. روی «ورود مدیریت» بزنید و رمز `ADMIN_PASSWORD` را وارد کنید.
4. رکورد آزمایشی بسازید و ذخیره شدن آن را در Google Sheets بررسی کنید.

## نکات
- اتصال واقعی به Google و انتشار در Vercel از داخل این گفتگو انجام نشده؛ باید مراحل بالا و تنظیم متغیرها را با حساب خودتان انجام دهید.
- مشاهده اطلاعات بدون ورود امکان‌پذیر است؛ همه عملیات تغییردهنده به ورود مدیریت نیاز دارند.
- اطلاعات پزشکی حساس را ثبت نکنید؛ فقط نتیجه تناسب شغلی و تاریخ‌ها نگهداری شود.
- برای استفاده سازمانی، محدودسازی تلاش ورود، پشتیبان‌گیری و بازبینی امنیتی توصیه می‌شود.
